雪之下雪乃 桌面宠物  使用说明
================================
版本 v1.7.0   （Windows 10 / 11 64 位）


一、怎么开始
------------------------------------------------
解压整个文件夹（不要只把 exe 拖出来），双击里面的 YukinoPet.exe。
她会出现在屏幕右下角。第一次启动可能要等两三秒。

不想用了：右键她 → 退出。


二、怎么和她互动
------------------------------------------------
  拖拽          按住她拖动。放下后她会抱怨一句。
  摸头          左键点她（点头效果最好，点身上也行）→ 扭头 + 脸红 + 台词。
  摸烦了        3 秒内连摸 5 次 → 她会转身背对你，5 秒后转回来。
  抱臂盯人      双击她；再双击一次解除。
  久坐提醒      连续用电脑 60 / 120 / 180 分钟，语气一级比一级重。
                到 240 分钟她会全屏挡住屏幕，直到你点"我知道了"。
                （万一按钮点不到，10 分钟后她会自动让开。）
  自己小跑      你 3 分钟没碰鼠标，她就可能自己挪一挪。
  睡觉          你 10 分钟没动静她会睡着，一动鼠标就醒。

  说明：看视频、读文档（人没走，只是没碰鼠标）也会计入"连续使用"，
        只有真的离开电脑 5 分钟以上，计时才会清零重算。


三、番茄钟 / 倒计时（专注模式）
------------------------------------------------
  开始          右键她 →「专注模式」→ 开始番茄钟。
                默认专注 25 分钟 + 休息 5 分钟，循环进行；
                每段结束会响铃声，她会说一句（口是心非的）鼓励。
  命名          面板上先给番茄钟起个名字（如"写报告"）再开始，
                每一条记录都会带上它，方便以后复盘。
  常用预设      高频名称点「存为常用」（最多 12 个），
                下次一键选用；点名称旁的 × 可以删掉。
  倒计时        右键 →「专注模式」→ 开始倒计时（默认 10 分钟）。
                走完同样有铃声和鼓励；提前取消会被她毒舌。
  提前停止      面板上点「停止」，或右键 → 专注模式 → 停止。
                中途放弃她会说傲娇的话——专注过的时长仍然计入统计。
  暂停          面板上「暂停 / 继续」，或右键菜单操作。

  专注面板      右键 →「专注模式」→ 打开专注面板：
                · 改专注 / 休息 / 倒计时的时长（自动记住）
                · 开关结束铃声、开关头顶倒计时显示
                · 今日完成 / 今日专注 / 连续天数 / 累计完成
                · 近 7 天专注分钟柱状图
                · 按名称统计：每个名字做了几次、完成率、总时长
                · 最近记录明细（时间 / 名称 / 实际时长 / 完成或中断）
                开始番茄钟时面板也会自动弹出来一次。

  头顶计时      番茄钟 / 倒计时运行时，她头顶会显示剩余时间 mm:ss。

  与久坐提醒    番茄钟或倒计时运行期间，久坐提醒暂时安静（计时照常累计）；
                结束后如果坐得够久，提醒会补上。

  待机闲聊      你在电脑前但没摸她的时候，她会偶尔自己说两句——
                天气、吐槽、关心。频率很低，睡着 / 跑动时不会说。


四、怎么换衣服 / 放大缩小
------------------------------------------------
  换衣服        右键她（点她身体附近都行）→「更换服装」→ 选一套。
                切换是淡入淡出，位置不会跳。重启后会记住上次的选择。
  放大缩小      鼠标在她身上滚轮，或右键菜单「放大 / 缩小 / 重置大小」，
                范围 50% ~ 250%。比例会记住，重启恢复。
  快捷键        先点一下她，然后：
                Ctrl+1 / 2 / 3 / 4   直接换四套服装
                Ctrl + = / -         放大 / 缩小
                Ctrl + 0             恢复默认大小
  其他菜单项    右键：回到默认位置 / 暂停提醒 / 静音 / 退出。


五、想改她说的话、提醒时间
------------------------------------------------
用记事本打开  resources\app\assets\config.json ：

  改台词        lines 下面按场景分组（摸头 pat、被摸烦 annoy、
                久坐 remind60/120/180/240、开场 startup、
                番茄钟 pomoStart/pomoDone/pomoQuit/pomoBreakOver 等），
                每类随便加几句，改完重启生效。
  改番茄钟      pomodoro → defaults（专注/休息/倒计时默认分钟、
                铃声开关）。注意：在专注面板里改过的时长会记住，
                优先于这里的默认值。
  改提醒时间    timers → remindMinutes，默认 [60, 120, 180, 240]（分钟）。
  改跑动频率    timers → walkChance（每次判定触发概率，默认 0.15）、
                walkRollSec（多少秒判定一次，默认 30）。
  改离开判定    timers → awayThresholdSec（默认 300 秒 = 5 分钟）。

注意：修改时保持逗号和引号完整，改坏了她会读不出配置。


六、常见问题
------------------------------------------------
  放久了点不到她  v1.5.0 已从架构上根治（立绘窗口永久可点，不再做鼠标穿透
                切换；另有心跳看门狗自动救活假死的画面）。如果你是从旧版
                升级，请退出旧版后使用这个新版本。万一遇到异常，
                右键任务栏图标退出后重新打开即可。
  看不到她      先确认不是在别的显示器边缘；右键菜单「回到默认位置」
                能把她叫回来（需要先能点到她）。
  她变成黑块    极少数显卡驱动下透明会失效。退出后用记事本打开
                resources\app\main.js，把开头这两行删掉再启动：
                  app.commandLine.appendSwitch('enable-transparent-visuals');
                  app.disableHardwareAcceleration();
  开机自启      把 YukinoPet.exe 的快捷方式放进"启动"文件夹
                （Win+R 输入 shell:startup 回车，把快捷方式拖进去）。
