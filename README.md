# 雪之下雪乃桌宠（Electron）

透明无边框、始终置顶的桌面宠物。四套参考服装切换、摸头互动、久坐分级提醒、待机随机跑动、自由缩放、番茄钟 / 倒计时 / 专注统计。

> 角色外观完全来自你提供的四张参考图（仅做抠图 / 裁切 / 缩放对齐，**没有任何重绘、改色或加配饰**）。

当前版本：**v1.7.0**（番茄钟可命名 + 常用预设 + 复盘明细 + 待机闲聊；修复/版本记录见文末）

## 安装与运行

```bash
npm install          # 安装 Electron（失败先设 ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/）
npm start            # 启动桌宠
```

双击 `launch.bat`（或桌面的 `启动雪乃桌宠.bat`）可免命令行启动。

**打包成可以发给别人的独立程序**（对方电脑不需要装 Node.js）：

```bash
npm run build        # 产物在 release/YukinoPet-win32-x64/
```

把整个 `YukinoPet-win32-x64` 文件夹压缩发出去，对方解压后双击 `YukinoPet.exe` 即可。
包内附 `使用说明.txt`（从项目根目录复制）。**刻意不用 asar**：收件人可直接编辑
`resources/app/assets/config.json` 改台词和阈值。

## 功能一览

| 功能 | 触发方式 |
|---|---|
| 拖拽移动 | 按住角色拖动（会挣扎，放下后抱怨）；拖到屏幕边缘会自动留 80px 可见 |
| 摸头 | 左键单击角色头部区域（扭头 + 脸红 + 台词） |
| 摸烦了 | 3 秒内连摸 5 次 → 转身背对 5 秒 |
| 抱臂盯人 | 双击角色（再双击解除） |
| 更换服装 | 右键（立绘附近即可）→ 更换服装；或 Ctrl+1~4。200ms 淡入淡出，位置不跳 |
| 缩放 | 角色上滚轮 / Ctrl+滚轮 / 菜单 / Ctrl+=、Ctrl+-、Ctrl+0（0.5x ~ 2.5x，底部锚点不动） |
| 久坐提醒 | 60 / 120 / 180 分钟分级台词；240 分钟全屏挡屏，点"我知道了"让开（10 分钟无响应自动让开） |
| 番茄钟 | 右键 → 专注模式 → 开始番茄钟（专注 25 分钟可自定义 → 铃声 + 鼓励台词 → 休息 5 分钟 → 自动下一轮）；可命名（如"写报告"）；头顶 mm:ss 倒计时徽章；提前停止有傲娇台词 |
| 倒计时 | 右键 → 专注模式 → 开始倒计时（默认 10 分钟，可自定义）；走完铃声 + 鼓励台词 |
| 专注面板 | 右键 → 专注模式 → 打开专注面板：暂停/停止、改时长（自动记住）、命名与常用预设、今日/连续/累计统计、近 7 天柱状图、按名称统计、最近记录明细 |
| 待机闲聊 | 人在电脑前但没摸她时，偶尔自言自语（天气/吐槽/关心，低频不吵） |
| 待机跑动 | 系统空闲 3 分钟后，每 30 秒 15% 概率小跑（自动避开屏幕边缘，不会原地空跑） |
| 睡觉 | 空闲 10 分钟进入 SLEEP，一动鼠标就醒 |
| 暂停提醒 / 静音 / 退出 / 回到默认位置 | 右键菜单 |

- 连续使用计时：系统空闲 < 5 分钟都算"人在"（看视频/读文档也累计）；离开 ≥ 5 分钟清零重算；
  系统休眠挂起的时间不计入（墙钟漂移校准）。
- 上次选择的服装、缩放、静音、暂停状态保存在 `%APPDATA%/yukino-pet/settings.json`，重启自动恢复。
- **架构（v1.5.0）**：桌宠窗口 = 立绘大小、**永久可交互**——程序从头到尾从不对它调
  `setIgnoreMouseEvents`，所以"放久后点不到"在结构上不可能发生；台词气泡是独立的
  **永久穿透**小窗口（创建时设置一次，之后永不再动）。配合心跳看门狗（渲染层 5 秒报活，
  主进程 35 秒收不到就自动重载）和每 10 分钟一次的置顶/启用自愈，锁屏、息屏、睡眠恢复
  都不影响交互。
- **番茄钟（v1.6.0）**：计时引擎在主进程、基于墙钟（睡眠唤醒后自动补算），不依赖渲染层
  定时器——画面假死被看门狗重载也不会丢计时。结束时铃声由气泡窗口用 Web Audio 合成
  （无音频文件）。番茄钟 / 倒计时运行期间久坐提醒静默（时长照常累计，结束后若仍超阈值
  会补弹）。统计记录存 `%APPDATA%/yukino-pet/pomodoro.json`（保留 90 天）。

| 想改什么 | 位置 |

| 连摸生气 | `timers.annoyPatCount` / `annoyWindowMs` / `annoyDurationMs` |
| 气泡时长 | `timers.bubbleMs` |

## 替换服装图片

1. 准备透明背景 PNG（或先跑 `python tools/prepare_assets.py` 做抠图 + 头部对齐，参考 `tools/preview.png`）。
2. 覆盖 `assets/outfits/outfitN.png`（保持 440x640 画布，头顶 y≈30、头高 ≈110、面部中心 x=220）。
3. 在 `config.json` 里微调该套的 `scale / offsetX / offsetY`（命中测试会同步这些参数）。
4. 重启。

## 已知取舍

- ANNOY 的"转身背对"用水平镜像实现（参考图没有背面素材，不做重绘）。
- 双击"抱臂盯人"用轻微放大实现（同理，无专用素材）。
- 静音 = 不弹出台词气泡（本作没有配音，气泡即声音）。
- 入睡后（空闲 10 分钟）不再触发待机跑动，直到用户回来。
- **立绘矩形内的透明区域（比如手臂旁的空隙）也会接住鼠标**（这是 v1.5.0 用稳定性换来的：
  窗口永远可交互、不做逐像素穿透切换）。窗口边界紧贴立绘，影响范围很小。
  摸头 / 拖拽 / 右键在窗口内任意位置都有效。

### v1.7.0 —— 命名番茄钟 / 常用预设 / 复盘明细 / 待机闲聊

- **命名番茄钟**：面板里输入名称（≤20 字）再开始，每条统计记录都带名称；
  计时中面板显示当前名称。
- **常用预设**：把高频名称"存为常用"（最多 12 个），一键选用、可删除，跨重启记住。
- **复盘数据**：面板新增「按名称统计」（每个名称的次数 / 完成率 / 总专注分钟，按时长降序）
  和「最近记录」明细（最近 60 条：日期时间 / 名称 / 类型 / 实际时长 / 完成或中断）；
  底层记录全部带名称存 `pomodoro.json`，保留 90 天。
- **待机闲聊**：人在电脑前但没摸她时（空闲 1~5 分钟），低频自言自语——天气、吐槽、
  关心（12 句，洗牌袋；两次间隔 ≥3 分钟；睡着 / 跑动 / 盯人 / 挡屏时不说话）。
- 验证：node --check 全过；仿真测试扩到 28 项全 PASS（名称记录 / presets 去重持久化 /
  按名称汇总 / 明细排序）。

### v1.6.0 —— 新增番茄钟 / 倒计时 / 专注统计

- **番茄钟**：专注（默认 25 分钟，可自定义）→ 铃声 + 鼓励台词 → 休息（默认 5 分钟，可自定义）
  → 自动进入下一轮；提前停止有傲娇台词，且按实际专注时长计入统计。
- **独立倒计时**：任意时长（默认 10 分钟），走完铃声 + 鼓励台词，提前取消有傲娇台词。
- **专注面板**：独立小窗口（可拖动、置顶）——暂停/停止、三处时长设置（自动记住）、
  结束铃声与头顶倒计时开关、今日完成 / 今日专注 / 连续天数 / 累计完成、近 7 天柱状图。
- **计时可靠性**：引擎在主进程、基于墙钟，渲染层假死重载 / 系统睡眠唤醒都不丢计时；
  铃声用 Web Audio 合成（无音频文件依赖，放开 autoplay 限制）。
- **久坐静默**：番茄钟 / 倒计时运行期间久坐提醒（含 240 分钟挡屏）全部静默，
  时长照常累计，结束后若仍超阈值自动补弹。
- **台词**：新增 pomoStart / pomoDone / pomoQuit / pomoBreakOver 四组（各 8 句，洗牌袋）。
- 验证：node --check 全过；`tools/test-pomodoro.js` mock 墙钟仿真 24 项全 PASS
  （状态机循环 / 暂停冻结 / 统计口径 / 配置持久化 / 洗牌袋）。

### v1.5.0 —— 架构级根治"待机久了无法触碰"

| 问题 | 修复 |
|---|---|
| **待机久了仍无法触碰 / 拖不动**（v1.4.0 轮询方案下仍复现） | v1.4.0 的根因诊断（`forward:true` 转发失效）没错，但"轮询光标位置切换穿透"仍然依赖 `setIgnoreMouseEvents` 这个 API 本身在 Windows 长时间运行 / 锁屏 / DWM 事件后的可靠性——实测它**整窗口的点击开关状态也会静默漂移**。v1.5.0 改为架构级根治：**彻底废除穿透切换**。桌宠窗口 = 立绘大小、永久可交互（从不调用该 API）；气泡拆成独立小窗口、永久穿透（创建时设置一次，之后永不再动）。参考 VPet / Shimeji 等长期运行验证过的同类架构 |
| 渲染层静默假死（定时器还在、事件全死） | 心跳看门狗：渲染层每 5 秒向主进程报活；主进程 35 秒收不到心跳 → 自动重载渲染层（1 小时内最多 6 次，防死循环）。`backgroundThrottling: false` 全窗口生效 |
| 放久后置顶失效 / 被其他窗口盖住 | 每 10 分钟 + 睡眠恢复 / 解锁屏幕时执行 `reassertWindows()`（重新 setEnabled + screen-saver 级置顶 + moveTop） |
| 挡屏提醒被看门狗重载误杀 | 重载时同步退出挡屏状态，不会出现"人回来了挡屏还挂着"或"挡屏卡死" |
| 气泡随角色移动脱节 | 角色移动 / 缩放 / 换装时气泡窗口实时跟随，台词走 IPC |

## 修复记录（v1.4.0，相对 v1.3.0）

| 问题 | 修复 |
|---|---|
| **放久以后点不到、拖不动**（锁屏/息屏/窗口隐藏后必现） | 根因：Windows 上 `setIgnoreMouseEvents(true,{forward:true})` 的鼠标转发会静默失效（Electron #1335 及多个同类项目踩坑记录），渲染层收不到 mousemove 后穿透状态永远翻不回来。重写为**主进程轮询仲裁**：120ms 轮询系统光标位置（Win32 API，不经过事件链），光标在立绘区域内→可交互，否则穿透；拖拽/菜单/挡屏期间强制可交互；每 5s 强制重发自愈；渲染层未就绪时按整窗可交互处理（失败模式=能点，绝不是点不到） |
| 放久后跑动/提醒/气泡停摆 | `backgroundThrottling:false`，禁止 Chromium 对"被遮挡窗口"的定时器降频 |
| 睡眠/锁屏恢复后状态可疑 | `powerMonitor` resume/unlock-screen 事件强制重发穿透状态 + 补发空闲时长 |
| 渲染进程崩溃后仲裁状态残留 | 崩溃回调里复位 dragging/menuOpen 并强制重发 |

## 修复记录（v1.3.0，相对 v1.0.0）

| 问题 | 修复 |
|---|---|
| 透明窗口在部分机器变黑/蓝矩形 | GPU 组合改为 `enable-transparent-visuals` + 禁用硬件加速，补 `backgroundColor:'#00000000'`，去掉互相矛盾的 `in-process-gpu`；main.js 顶部有切换说明 |
| 每次鼠标移动都调 `setIgnoreMouseEvents`，Windows 上系统鼠标卡顿 | 穿透状态去重（只有变化才发 IPC）；命中测试从逐次 `getImageData` 改为一次性缓存 alpha 数组纯查表 |
| 图片加载失败/超时 → 命中画布空白 → 全部鼠标交互静默失效 | 两级命中：alpha 精确 → 立绘矩形兜底，**任何情况下都能拖动**；图片缺失时气泡明确提示 |
| 启动图片加载竞态（activeIdx 赋值晚于 load 回调 + 300ms 硬等） | `await Promise.all(imgs.map(i => i.decode()))` 全部解码后再设置 activeIdx 并构建命中画布 |
| CSP `default-src 'self'` 在 file:// 下可能拦本地图片 | 显式声明 `img-src 'self' file: data:` |
| 双击"盯人"永远不生效（CSS animation 覆盖静态 transform） | 状态类改为互斥：stare 取代 breathe（而不是叠加）；stare 开启时 ANNOY 转身也不再被覆盖 |
| 待机跑动在屏幕边缘被静默 clamp，原地空跑 | 跑动前先查屏幕可用空间规划方向，没空间的一侧自动翻转/缩短/放弃 |
| 看视频/读文档（60 秒不碰鼠标）久坐计时停止 | 离开阈值放宽到 5 分钟；墙钟差检测系统休眠，挂起时间不计入 |
| 角色移动后穿透状态不刷新，透明区继续吃点击 | 跑动结束 / 缩放 / 换装 / 拖拽结束 / 挡屏结束后主动刷新 |
| 右键菜单只在角色像素上可用 | 放宽到立绘矩形外扩 24px |
| 240 分钟挡屏只遮一小块，且结束后位置被重置回右下角 | 挡屏铺满当前显示器工作区；进入前记住原位置，退出时精确还原；10 分钟无响应自动让开兜底 |
| 气泡 max-width 不随缩放，0.5x 时溢出被裁 | 气泡尺寸全部乘 `--z` |
| 命中测试忽略 outfit 的 scale/offset 微调 | 命中画布绘制时应用同一套变换（含 zoom 换算） |
| 窗口尺寸在 config 与 main.js 重复定义 | 单一数据源：main.js 读 config.json 的 window 段 |
| 多显示器只认主屏 | clamp / 挡屏 / 屏幕信息全部改用 `getDisplayNearestPoint` |
| 无单实例锁 | `requestSingleInstanceLock` |
| 挡屏期间可缩放导致立绘/遮罩错乱 | 挡屏期间缩放入口禁用 |
| 静音时已显示的气泡不消失 | 静音立即收起气泡 |
| 台词"洗牌袋"实际没去重（可能连续重复） | 真 Fisher-Yates 洗牌袋，袋内不重复、跨袋不与上一句重复 |
| 4 条台词语病 | 已修正（女仆装两条、annoy 一条、struggleTalk 一条） |
